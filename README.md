# `# Günlük Kalori Takip Uygulaması` 

```
Python ile yazılmış, gün içinde tükettiğiniz yiyecekleri ve kalori miktarlarını
pratik bir şekilde takip etmenizi sağlayan konsol uygulaması.
```

# `## Özellikler` 

- `**Öğün Ekleme:** Yiyecek adı ve kalori miktarını kaydetme` 

- `**Günlük Özet:** Tüketilen tüm öğünleri ve toplam kaloriyi görüntüleme` 

- `**Sıfırlama:** Yeni bir gün için günlük listeyi temizleme` 

- `**Hata Koruması:** Geçersiz veri girişlerinde uygulamanın kapanmasını önleme` 

# `## Gereksinimler` 

- `Python 3.6 veya üzeri` 

# `## Kullanım` 

`1. `main.py` dosyasının bulunduğu dizinde terminali/komut satırını açın.` 

`2. Uygulamayı çalıştırın:` 

```
```bash
```

```
python main.py
```
